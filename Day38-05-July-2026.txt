# Day 19 — Git Deploy, RDS Skeleton, Rolling Strategy, Ping Check

## Ansible — Deploy App Using Git
---
- name: Install git repository for Pathnex
  hosts: all
  become: yes

  tasks:
    - name: Install Git
      yum:
        name: git
        state: present

    - name: Clone git repository
      git:
        repo: "https://github.com/pathnex/app.git"
        dest: /opt/pathnex

## Kubernetes — Deployment Rolling Update (Detailed)

apiVersion: apps/v1
kind: Deployment
metadata:
  name: pathnex-rolling
spec:
  replicas: 3
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 2
      maxUnavailable: 1
  selctor:
    matchLabels:
      app: pathnex-app
  template:
    metadata:
      labels:
        app: pathnex-app
    spec:
      containers:
        - name: app
          image: nginx

## Shell Script — Check Internet Connectivity

#!/bin/bash

ping -c 2 google.com &> /dev/null

if [ $? -eq 0 ]; then
  echo "Ping is reachable"
else
  echo "Ping is unreachable"
fi


# Approvals
## Jenkins Pipeline — Manual Approval
You will learn how to **pause pipeline until manual approval**.

pipeline {
    agent any
    environment {
        INSTITUTE_NAME = "Pathnex"
    }
    stages {
        stage('Checkout') {}
        stage('Build') {}
        stage('Deploy') {
            steps {
                input message: "Approve deployment for $INSTITUTE_NAME ?"
                sh 'echo "Deployment approved and executed for $INSTITUTE_NAME"'
            } 
        }
    }
}

## GitLab CI — Manual Approval Job
You will learn how to **use manual jobs in GitLab CI for approvals**.

stages:
  - deploy

variables:
  INSTITUTE_NAME: "Pathnex"

deploy:
  stage: deploy
  image: maven:3.8.1-jdk-17
  script: 
   - echo "Ready to deploy in $INSTITUTE_NAME"
  when: manual

Fix the following broken files:

## 🔹 Ansible (broken)

- name "Broken"
 hosts: all
 tasks:
   - name: Install
     yum:
       name: nginx
       state present

Fixed
---
- name: Broken
  hosts: all
  become: yes

  tasks:
    name: Install
    yum:
      name: nginx
      state: present

# Matrix Builds

## 🔹 Jenkins Pipeline — Matrix Build
You will learn how to **run the same build on multiple environments**.

pipeline {
    agent any
    environment {
        INSTITUTE_NAME = 'pathnex'
    }
    stages {
        stage('Matrix Build') {
            matrix {
                axes {
                    axis {
                        name 'JAVA_VERSION'
                        values '8', '11', '17'
                    }
                }
                stages {
                    stage('Build') {
                        steps {
                            sh "echo 'Building with JAVA ${JAVA_VERSION}'"
                        }
                    }
                }
            }
        }
    }
}

## 🔹 GitLab CI — Matrix Jobs
You will learn how to **run jobs across multiple environments using matrix**.

stages:
  - build

build-env:
  - stage: build
    parallel:
      matrix:
        - IMAGE: "maven:3.8.1-openjdk-8"
          JAVA_VERSION: "8"
        - IMAGE: "maven:3.8.1-openjdk-11"
          JAVA_VERSION: "11"
        - IMAGE: "maven:3.9.9-eclipse-temurin-17"
          JAVA_VERSION: "17"
    
    image: $IMAGE

    script:
     - java --version
     - echo "Building with Java $JAVA_VERSION"

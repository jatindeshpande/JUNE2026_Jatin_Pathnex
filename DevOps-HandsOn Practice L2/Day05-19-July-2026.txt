# Day 05 — Advanced CI/CD and Infrastructure Provisioning

## Jenkinsfile — With Git Integration and Testing

```groovy

pipeline {
    agent any
    environment {
        ENVIROMENT = "Production"
    }
    stages {
        stage('Checkout') {
            steps {
                git 'https://github.com/pathnex/sample-repo.git'
            }
        }
        stage('Build') {
            steps {
                echo 'Build the project from Git repository'
            }
        }
        stage('Test') {
            steps {
                echo 'Running unit tests'
            }
        }
        stage('Deploy') {
            steps {
                echo 'Deploying the application'
            }
        }
    }
}

## Ansible — Create User and Set Permissions
---
- name: Create a user and set permissions
  hosts: all
  become: yes

  tasks:
    - name: Create user
      user:
        name: pathnex
        state: present
        shell: /bin/bash

    - name: Set permissions for the user
      file:
        path: /home/pathnex
        owner: pathnex
        group: pathnex
        mode: '0755'

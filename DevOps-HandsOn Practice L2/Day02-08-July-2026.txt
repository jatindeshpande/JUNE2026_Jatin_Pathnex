# Day 02 — Services & Tags

## Ansible — Install & Enable Nginx

---
- name: Install and start nginx using Ansible
  hosts: all
  become: yes

  tasks:
    - name: Install nginx
      yum:
        - name: nginx
          state: present

  tasks:
    - name: Enable nginx service
      service:
        - name: nginx
          state: started
          enabled: yes

# Kubernetes — Deployment with 2 Replicas

apiVersion: apps/v1
kind: Deployment
metadata:
  name: pathnex-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: pathnex-app
  template:
    metadata:
      labels:
        app: pathnex-app
    spec:
      containers:
        - name: app
          image: nginx
          ports:
            - containerPort: 80

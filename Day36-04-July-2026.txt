# Deployment Simulation

## Jenkins Pipeline — Simulated Deployment
You will learn how to **simulate deployment to different environments**.

pipeline {
    agent any
    parameters {
        choices(name: 'ENVIRONMENT', choices['dev', 'qa', 'prod'], Description: 'Simulate multi-environment pipeline')
    }

    environment {
        INSTITUTE_NAME = "Pathnex"
    }
    stages {
        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }
        stage('Deploy') {
            steps {
                sh 'echo "Deploying $INSTITUTE_NAME application to $ENVIRONMENT"'
            }
        }
    }
}

## GitLab CI — Deployment Simulation
You will learn how to **simulate deployment in GitLab CI using environment variable**.

stages:
  - deploy

variables:
  INSTITUTE_NAME = "Pathnex"
  ENVIRONEMT = "staging"

deploy:
  stage: deploy
  image: maven:3.8.1-jdk-17
  script:
   - echo "Deploying $INSTITUTE_NAME in environment $ENVIRONEMT"

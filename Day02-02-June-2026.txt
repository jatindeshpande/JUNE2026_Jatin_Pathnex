Writing cmds which we encountered

cd - change dir
pwd - present working directory
ls - list
ls -la  - l = long listing format, a = show all files
ls -lahrt   - l = long listing format, a = show all files, h = human readable size, r = reverse the sort order, t = sort by modification time

rename in Linux
mv file.txt file1.txt

move file to a certain directory
mv file.txt /home/ec2-user/docs
